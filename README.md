# Описание
**Mood Diary** — минималистичное Android-приложение для фиксирования своего настроения, анализа эмоциональной динамики и формирования привычки эмоциональной осознанности.  
Все данные хранятся **локально** в базе данных **Room**, а ежедневные напоминания помогают вести дневник регулярно.

# Функциональность

## Запись настроения
- выбор эмоции;
- ввод описания;
- установка даты и времени;
- локальное сохранение записи.

## Управление записями
- редактирование записей;
- удаление;
- поиск;
- фильтрация по эмоциям;

## Аналитика и статистика
- графики изменения настроения;

## Напоминания
- ежедневные уведомления (WorkManager).

---

# 🧭 Пользовательские сценарии

### Главный экран
- отображение всех записей;
- строка поиска;
- фильтры эмоций;
- кнопка добавления записи.

### Экран добавления / редактирования
- выбор эмоции;
- ввод описания;
- дата и время;
- сохранение.

### Экран статистики
- графиков изменений настроения;
- распределение эмоций.

# Технологии

| Стек | Описание |
|------|----------|
| **Kotlin** | язык разработки |
| **Room** | локальная база данных |
| **MVI + ViewModel** | архитектура и управление состоянием |
| **Coroutines + Flow** | асинхронность |
| **RecyclerView + DiffUtil** | списки |
| **Material Icons** | иконки |
| **WorkManager** | уведомления |
